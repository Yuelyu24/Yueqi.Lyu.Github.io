# Yueqi Lyu — Personal website

A static academic website for an undergraduate at Xi'an Jiaotong-Liverpool University. It introduces research interests, selected projects, contact details and CSI205TC network notes.

## Pages

- `index.html`: introduction and selected work.
- `projects.html`: project descriptions with optional topic filtering.
- `network.html`: network layers, HTTPS/TLS and testing methods.
- `contact.html`: university email and GitHub profile.
- `404.html`: custom missing-page response.

## Run locally

Open `index.html` in a browser. No dependencies or build step are needed. Clipboard permissions can differ for local files; select the text manually if copying is blocked.

## Publish

Put these files and the `css`, `js` and `assets` directories in the root of the `yuelyu24.github.io` repository. Configure GitHub Pages to use the `main` branch and root folder. Intended URL: `https://yuelyu24.github.io/`.

## Edit

Personal content is in the HTML files. Shared styling is in `css/style.css`; interactions are in `js/main.js`. Internal links are relative. All visual assets are local SVGs. There are no external fonts, trackers, remote libraries, form services or API credentials.

Project descriptions do not assert publication or provide invented project links. The network page is a conceptual notebook, not a record of completed measurements. Private coursework evidence is maintained separately from this public website.
